# 🌳 ls-tree

交互式硬盘目录清单生成工具。选择硬盘，一层层进入文件夹，自动生成完整的目录树清单，包含每个文件夹的文件数量。

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-ISC-green)
![Node](https://img.shields.io/badge/node-%3E%3D14.0.0-brightgreen)

## 功能

- 自动检测所有已挂载的硬盘
- 支持一层层进入深层目录，灵活选择
- 递归扫描目录树，显示每个文件夹的文件数量
- 自动跳过无权限读取的文件夹（如 macOS 系统隐藏目录）
- 实时进度条，显示已扫描文件夹数和文件数
- 清单保存位置可选：桌面 或 硬盘根目录
- 文件名自动包含硬盘名和目录名，简洁清晰

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/babytutu/ls-tree.git
cd ls-tree
```

### 2. 运行

```bash
node tree.js
```

### 交互流程

1. 选择硬盘
2. 一层层进入文件夹，直到找到目标目录
3. 选择“选择当前目录（开始扫描）”
4. 选择清单保存位置（桌面 或 硬盘根目录）
5. 自动生成清单文件

### 菜单说明

| 选项                        | 操作                   |
| --------------------------- | ---------------------- |
| 📁 文件夹名                 | 进入该文件夹           |
| 🔙 返回上一层               | 回到父目录             |
| ✅ 选择当前目录（开始扫描） | 确认当前目录，开始扫描 |

## 清单示例

```text
📂 /Volumes/tutu/pic/2025
📅 2026-07-30 14:30:00
──────────────────────────────────────────────────
📁 2025
  📁 20251206孔庙 (19个文件)
  📁 20251208虎跑 (9个文件)
  📁 20251209鼓楼 (12个文件)
──────────────────────────────────────────────────
📊 4 个文件夹，40 个文件
```

## 生成的文件

### 文件名格式

```text
{硬盘名}_{目录名}_目录清单_{日期}.txt
```

例如选择 `tutu` 硬盘下的 `20251206孔庙` 文件夹，生成：

```text
tutu_20251206孔庙_目录清单_20260730.txt
```

选择“全盘”扫描，生成：

```text
tutu_全盘_目录清单_20260730.txt
```

### 保存位置

- 桌面：清单保存在 `~/Desktop/`，方便查看
- 硬盘根目录：清单保存在硬盘根目录，插上硬盘就能看到

## 使用场景

- 备份前了解硬盘内容
- 定期生成目录清单，归档保存
- 不插硬盘也能查看文件结构
- 对比不同时间的目录变化
